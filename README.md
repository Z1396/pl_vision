# pl_vision

## 项目概述

pl_vision 是一个基于计算机视觉的机器人自动瞄准系统，在 superpower 开源的 2025 视觉代码基础上进行了适配和扩展。该系统主要用于机器人竞赛中的目标检测、跟踪和瞄准，支持多种任务模式和实时数据可视化。

### 主要功能特点

- **自动瞄准系统**：基于模型预测控制（MPC）的目标检测、跟踪和瞄准
- **能量机关识别**：支持能量机关的检测和跟踪
- **网页调试功能**：通过 WebSocket 实现实时数据可视化和视频流传输
- **多任务支持**：自动瞄准（auto_aim）、能量机关（auto_buff）、全向感知（omniperception）
- **模块化设计**：清晰的代码结构和模块划分，便于维护和扩展
- **实时性能**：多线程设计，保证系统的实时响应能力

## 快速开始

### 环境要求

- Ubuntu 20.04 或更高版本
- C++17 或更高版本的编译器
- CMake 3.16.3 或更高版本
- 所需依赖库：OpenCV、Eigen、nlohmann/json、fmt、yaml-cpp、OpenVINO

### 安装与编译

1. **克隆项目代码**

2. **安装依赖项**
   ```bash

   sudo apt update
   sudo apt install libopencv-dev libeigen3-dev nlohmann-json3-dev libfmt-dev libyaml-cpp-dev
   ```

3. **编译项目**
   ```bash
   mkdir build && cd build
   cmake ..
   make -j4
   ```

## 核心功能模块

### 1. 自动瞄准系统（auto_aim）

#### 功能概述
- 目标检测：支持传统图像处理和 YOLO 深度学习两种方法
- 目标跟踪：基于多目标跟踪算法和扩展卡尔曼滤波器（EKF）
- 坐标解算：相机坐标系到云台坐标系再到世界坐标系的转换
- 轨迹规划：基于模型预测控制（MPC）算法的目标预测和云台控制
- 时间同步：通过时间戳对齐解决相机采集与云台控制之间的时间差

#### 主要文件
- `tasks/auto_aim/detector.hpp`：传统目标检测器
- `tasks/auto_aim/yolo.hpp`：YOLO 目标检测器
- `tasks/auto_aim/tracker.hpp`：目标跟踪器
- `tasks/auto_aim/solver.hpp`：坐标解算器
- `tasks/auto_aim/aimer.hpp`：瞄准器

### 2. 能量机关系统（auto_buff）

#### 功能概述
- 能量机关检测和识别
- 旋转目标跟踪
- 预测命中点计算

### 3. 网页调试功能

#### 功能概述
- 实时视频流显示
- 算法数据可视化（装甲板位置、角度、速度等）
- 云台状态监控
- 性能指标显示（帧率、延迟等）

#### 使用方法
1. **启动 HTTP 服务器**
   ```bash
   python3 -m http.server 8000
   ```

2. **运行视觉程序**
   ```bash
   ./auto_aim_test -m true -g true
   ```

3. **访问调试网页**
   在浏览器中打开：`http://localhost:8000/web/index_working.html`

#### 网页功能
- **视频流窗口**：实时显示相机采集的图像和检测结果
- **信息面板**：显示装甲板数量、帧延迟、目标 ID、发射状态等关键信息
- **数据图表**：实时绘制各种算法数据的变化趋势，包括：
  - 装甲板位置和航向角
  - 云台角度和指令角度
  - 目标位置、速度、角度和尺寸
  - 卡尔曼滤波残差
  - 系统性能指标（帧延迟、帧率）

## 配置文件说明

### 配置文件结构

项目使用 YAML 格式的配置文件，默认路径为 `configs/standard3.yaml`。主要配置项包括：

- **敌方目标颜色**：`enemy_color`（"red" 或 "blue"）
- **神经网络参数**：YOLO 模型路径、置信度阈值等
- **传统检测参数**：阈值、灯条比例范围等
- **跟踪器参数**：最小检测次数、最大临时丢失计数等
- **瞄准器参数**：偏航角补偿、俯仰角补偿等
- **相机参数**：内参、外参、曝光时间等
- **控制板参数**：CAN ID、接口名称等
- **规划器参数**：开火阈值、最大加速度等

### 关键参数调整

| 参数 | 含义 | 取值范围 | 调整建议 |
|------|------|----------|----------|
| `enemy_color` | 敌方目标颜色 | "red" 或 "blue" | 根据实际比赛情况选择 |
| `min_confidence` | 检测置信度阈值 | 0.0-1.0 | 建议 0.8-0.9，平衡检测率和误检率 |
| `use_traditional` | 是否使用传统检测 | true/false | 光线条件好时建议 false，使用 YOLO |
| `max_temp_lost_count` | 最大临时丢失计数 | 5-50 | 运动目标建议 15-20 |
| `yaw_offset`/`pitch_offset` | 偏航/俯仰角补偿 | -5.0-5.0 度 | 根据实际安装误差调整 |
| `low_speed_delay_time` | 低速延迟时间 | 0.05-0.2 秒 | 子弹速度慢时增大，快时减小 |
| `max_pitch_acc` | 最大俯仰角加速度 | 5-15 rad/s² | 调大响应快但易抖，调小运动平滑但响应慢 |

## 与下位机联调

### 通信协议

- **通信方式**：FDCAN 总线通信
- **CAN ID 配置**：
  - 四元数 CAN ID：`0x100`
  - 子弹速度 CAN ID：`0x101`
  - 发送 CAN ID：`0xff`
- **CAN 接口**：默认 `can0`

### 数据交互

- **从下位机接收**：
  - IMU 数据：四元数表示的云台姿态
  - 子弹速度：当前子弹速度
  - 角速度：偏航和俯仰角速度
  - 弹数：当前云台弹数

- **向下位机发送**：
  - 云台控制指令：目标角度、速度、加速度
  - 开火指令：是否开火

### 联调步骤

1. **硬件检查**：
   - 确认 FDCAN 总线连接正常
   - 确认相机与下位机供电稳定
   - 确认陀螺仪机械结构无松动

2. **软件检查**：
   - 配置文件参数正确设置
   - FDCAN 总线驱动正常加载
   - 相机驱动正常工作

3. **测试流程**：
   - 单独测试相机采集功能
   - 测试 FDCAN 总线通信
   - 测试云台手动控制
   - 集成测试目标检测和跟踪
   - 测试自动瞄准功能
   - 测试开火功能

## 故障排查

### 常见问题及解决方法

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 目标检测失败 | 光线过暗/过亮 | 调整相机曝光时间和增益 |
| 跟踪不稳定 | 目标运动过快 | 增大最大临时丢失计数 |
| | 检测结果波动大 | 调整卡尔曼滤波参数 |
| 瞄准精度低 | 相机标定不准确 | 重新进行相机标定 |
| | 时间同步误差 | 检查时间戳对齐逻辑 |
| | 子弹速度估计不准 | 校准子弹速度测量装置 |
| CAN 通信失败 | CAN 总线连接松动 | 检查 CAN 总线连接 |
| | CAN ID 配置错误 | 检查配置文件中的 CAN ID 设置 |
| 网页调试无数据 | WebSocket 连接失败 | 检查网络连接和 IP 配置 |
| | 端口被占用 | 检查 8080 端口是否被占用 |

## 注意事项与最佳实践

### 安全注意事项

- **人员安全**：调试过程中，确保云台运动范围内无人员和障碍物
- **设备安全**：避免云台快速转动时与其他设备碰撞
- **电气安全**：确保 FDCAN 总线和相机设备的供电稳定，避免短路

### 系统调试建议

- **模块化调试**：先单独调试每个模块，再进行集成测试
- **渐进式调优**：从静态目标开始，逐步过渡到动态目标
- **参数记录**：记录不同场景下的最佳参数配置
- **环境测试**：在不同光照、距离和背景条件下测试系统性能
- **日志分析**：开启详细日志，便于问题定位和性能分析

### 性能优化

- **计算加速**：使用 GPU 加速 YOLO 推理
- **内存管理**：避免频繁内存分配和释放
- **线程优化**：合理分配线程资源，避免线程竞争
- **算法调优**：根据硬件性能调整算法复杂度
